Inside Franok

How a token chooses its bank

Each layer has eight feed-forward banks. The last token of the previous group rotates the assignment for the next eight tokens. Move the controls to trace one token through a layer.

What happens at each layer

  1. Eight query heads read earlier tokens through two shared key/value heads.
  2. The selected bank applies a gated feed-forward transformation. The other seven banks wait.
  3. A residual connection carries the result to the next layer. The output uses the same weights as the token embedding.

Franok was trained on 256-token windows. The chat app saves older messages and can retrieve matching turns for the prompt. “Find in session” searches the full saved conversation.
